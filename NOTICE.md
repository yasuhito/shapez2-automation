# Third-party software

This repository contains independently written adapter and client source.
It does not distribute shapez 2 assemblies, assets, saves, or third-party mod source.
The adapter must be built against a legally installed copy of shapez 2, which is
owned by tobspr Games and remains subject to its own terms.

The game already supplies Unity, Unity.Mathematics, Newtonsoft.Json, and other
assemblies referenced at build time. They are not bundled by this project.
.NET SDK and Python are external build/runtime prerequisites.

Official API examples and Shapez Shifter were read as reference material:
- https://github.com/tobspr-games/shapez2-mod-samples
- https://github.com/tobspr-games/shapez2-shifter

Their source and dependencies are not included, built, installed, or redistributed
by this repository. No Shifter hooks or downloaded runtime packages are required.
